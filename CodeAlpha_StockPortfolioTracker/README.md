# 📊 CodeAlpha Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

This project allows users to enter stock symbols and quantities and calculates the total investment based on predefined stock prices.

## ✨ Features

- Displays available stocks
- Accepts stock symbol and quantity
- Calculates individual investment
- Calculates total portfolio investment
- Validates user input

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops
- Conditional statements

## ▶️ How to Run

```bash
python main.py
