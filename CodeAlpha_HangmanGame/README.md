# 🎮 CodeAlpha Hangman Game

A simple text-based Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

The game randomly selects a word from a predefined list. The player guesses the word one letter at a time.

The player can make a maximum of 6 incorrect guesses.

## ✨ Features

- Random word selection
- One-letter-at-a-time guessing
- Maximum 6 incorrect guesses
- Prevents duplicate guesses
- Winning and losing conditions
- Console-based interface

## 🛠️ Technologies Used

- Python 3
- Random module
